

# AI Interview Assistant & Gap Analyzer

An intelligent AI-powered platform that analyzes resumes against targeted job descriptions to highlight skill gaps, generate tailored interview questions, and build structured preparation roadmaps.

## 🚀 Features
- **Resume & JD Analysis:** Leverages Gemini AI to parse and identify skill mismatches.
- **Automated Mock Questions:** Generates technical and behavioral questions aligned with specific job roles.
- **Custom Prep Roadmap:** Creates step-by-step preparation schedules.
- **Secure Authentication:** JWT-based user authentication and protected API endpoints.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **AI Integration:** Google Gemini API
- **Auth:** JSON Web Tokens (JWT)
